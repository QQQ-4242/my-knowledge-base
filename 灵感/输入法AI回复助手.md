# 输入法AI回复助手 — 产品构想

## 一句话定位

聊天时，输入法自动根据对话上下文弹出 3 条可选回复，适配不同场景（调情/正式/长辈/幽默…），用户选一条直接发送。不跳出当前 App。

## 为什么是输入法

- 微信小程序无法在聊天页内嵌入按钮，只能粘贴→跳转→返回
- 捷径/快捷指令需要手动触发，不够自然
- **输入法键盘是唯一能在所有 App 的输入框上方直接渲染 UI 的载体**

## 核心体验

```
微信聊天页
    ↓ 输入框获得焦点
输入法键盘顶部出现一行建议条：
┌──────────────────────────────────┐
│ 💕 温柔版：好啊，那周末见~         │
│ 📝 正式版：好的，周末时间没问题。   │
│ 😏 幽默版：你请客我就来             │
└──────────────────────────────────┘
    ↓ 点选一条
文字填入输入框 → 手动发送或自动发送
```

## 技术方案

### 方案一：基于现有输入法 SDK 二次开发

- 讯飞/百度/搜狗输入法均提供 SDK
- 在键盘 View 顶部加一个 RecyclerView（Android）/ UIStackView（iOS）
- 监听输入框文本变化 → 调 AI API → 返回 3 条建议 → 渲染在建议条中
- 用户点选 → `inputConnection.commitText(text, 1)`

### 方案二：独立轻量输入法

- Android：继承 `InputMethodService`，键盘布局用标准 QWERTY + 顶部建议栏
- iOS：使用 `UIInputViewController`，自定义 `inputView`
- 优势：完全掌控 UI 和逻辑

### AI 接入

- 使用 DeepSeek API（便宜，￥1/百万 token）
- Prompt 模板：

```
根据以下对话上下文，生成3条回复建议：
1. 温柔/亲近版
2. 正式/尊敬版  
3. 幽默/轻松版

对话记录：
[对方]：明天有空吗？
[我]：（待生成）

要求：每条不超过30字，符合中文口语习惯。直接输出3条，不要解释。
```

- 可离线缓存常用回复，减少 API 调用

## 风险与替代

- 苹果审核：第三方输入法必须有完整键盘功能，不能只是"建议条"
- 替代方案：iOS 用 Keyboard Extension + NetworkExtension 组合
- 先做 Android 版验证，iOS 后续
