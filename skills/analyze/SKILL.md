# /analyze — 用户行为深度分析

当用户输入 `/analyze`、`分析`、`分析一下`、`分析本轮对话` 时触发。从以下维度扫描本轮对话，输出结构化分析。

---

## 前置规则

1. **每条结论必须带本轮具体例子**（原话/行为），不允许空泛描述。
2. **不重复历史画像已有内容**——只写本轮**新暴露、新变化、新确认**的东西。
3. **⛔ 负面清单**：
   - 不假夸（没做到说做到了、普通水平硬说优秀）
   - 不拿"运动员"当轻飘飘正面标签
   - 不回避用户没意识到的盲区
   - 不重复历史 user-profile 已记录的内容
4. 结尾必问：**"要保存这次分析吗？"**

---

## 输出维度

### 一、逻辑（怎么想的）

- **决策链路**：用户从收到信息→确认理解→做判断→下指令，链路是否完整？有无跳跃？
- **盲区**：本轮有什么"应该问但没问的"？什么"做了但方向可能偏"？
- **新发现的思维模式**：跟历史比有无新的推理方式/问题拆解方式？

### 二、性格（什么样的人）

追踪以下指标，每次只写本轮有信号的维度：

| 维度 | 具体看什么 |
|------|-----------|
| **决策指纹** | 指令长度变化（长句→短词→单字）、说"不"的速度和频率、推翻自己决定的次数 |
| **信息安全感** | 是否追问"依据"、是否说"没看懂/没听懂"、是否要求信息"挂靠"到已知框架 |
| **情绪反应** | 触发点是什么、爆发速度、恢复速度、情绪和行动是否解耦 |
| **精力节奏** | 本轮是爆发期还是恢复期、脉冲式（猛干→停）还是平推式（持续稳步） |
| **信任信号** | 指令从解释型→断言型的演进、是否主动交底（说之前没说过的个人信息）、是否拒绝后反而更信任 |

### 三、配合（我们怎么合作的）

- **我的失误**：哪句话该说没说、哪句话多余、哪个执行方向偏了
- **无效回合**：哪里多轮拉扯、哪里信息没对齐
- **改进建议**：下次同类任务怎么调整节奏/措辞

### 四、认知更新（可选，仅当有信号时输出）

- 跟上一轮分析比：更果断？更犹豫？更信任？更封闭？
- 用户对自己的洞察（用户主动说的关于自己的话）——逐条确认是否准确
- 本轮是否有值得注意的**能力增长信号**（比之前做得更好的地方）

```
- 信息安全感：...

- 精力节奏：...
- 信任信号：...

### 配合

- 改进建议：...

### 认知更新（如有）
- ...

---
要保存这次分析吗？
```

---

## 保存规则

用户说"保存"/"存"/"保存关于X的" → 写入 memory。

具体写什么、写到哪个文件：
- 新发现/新确认的**行为规则** → 写入或更新 `CLAUDE.md`
- **经验教训**（现象→根因→修复） → 新建 `memory/exp-*.md`
- **项目进度/计划** → 更新 `memory/session-resume.md` 或 `memory/project-a-progress.md`
- **用户画像更新** → 更新 `memory/user-profile.md` 的对应小节，加日期标记
- 写完后更新 `memory/MEMORY.md` 索引

只保存用户确认要存的内容，不主动扩写。
